## Short Description
MyPlaylist is a responsive multi-page website designed to showcase a personal collection of favorite songs, albums, and artists. The site features a structured layout with intuitive navigation, providing users with information about top tracks, popular albums, and artists.

## Features Implemented
* 5 fully functional HTML pages with interconnected navigation.
* Responsive design utilizing the Bootstrap grid system and CSS media queries.
* Interactive elements including tables and a feedback form.
* Structured layout utilizing semantic HTML5 tags (header, main, footer).
* Modern and consistent styling using custom CSS, Flexbox, CSS variables, and pseudo-classes.

## Technologies Used
* HTML5
* CSS3
* Bootstrap 5
* GitHub Pages (Hosting)
